svg> document commands:
  init [w] [h]            new canvas (default 800x600); disables undo/redo
  read <file.svg>         load svg file as current document
  save [file.svg]         save document (default: path from read)
  canvas [w] [h]          show canvas size, or resize it

edit commands (undoable):
  create <type> <id> [params...] [in <cid>]
        types: rect <x> <y> <w> <h> [fill] | circle <cx> <cy> <r> [fill]
               ellipse <cx> <cy> <rx> <ry> [fill] | line <x1> <y1> <x2> <y2> [stroke]
               text <x> <y> "content" | g
  delete <id>             remove shape (or whole subtree)
  move <id> <dx> <dy>     translate
  scale <id> <factor>     uniform scaling
  set <id> <attr> <value> set whitelisted attribute
  group <newGid> <id>...  collect existing shapes into a new container
  ungroup <gid>           dissolve a non-top-level container
  addto <gid> <id>        move a shape into a container (last child)
  front <id> / back <id>  z-order within siblings

display commands:
  tree [id]               structure tree with inline geometry
  show <id>               attribute details of one shape
  help                    this text

undo/redo:
  undo / redo             one edit command per unit; io commands lock them

  lines starting with '#' are comments; quote args containing spaces

plugin commands:
  stats  count shapes by type (DFS order), total leaves and containers
  dir    list entries of the current working directory
